# Asset sources

- Northstar and LendFlow: captures of their public live demos, 2026-10-01, converted to WebP for transfer size. The covers are editorial compositions using these real captures.
- Barrilito cover: original SVG editorial illustration of oil extraction and underground rock layers. It represents the subject, not a product screenshot, measured geography or a technical well diagram.
- Barrilito case page: inline SVG chart from `apps/spike/data/monthly_pulse.csv`, pinned Vaca Muerta repository commit `1c1c30eb9e29901048cbd812eb14f46c109e4439`. Absolute oil production in cubic metres; no live feed or extrapolation.
- Python, dbt, DuckDB, BigQuery, Next.js, GitHub and LinkedIn: Simple Icons 13.21.0, CC0. Logos retain their brand colors with adjacent labels. DuckDB uses a dark mark on its official yellow for contrast. Logos remain the trademarks of their owners. https://simpleicons.org/
- Meltano: official blue icon from https://github.com/meltano/meltano/blob/main/docs/docs/reference/images/icon.svg, downloaded 2026-10-01. Repo MIT license. Displayed with adjacent label.
- Favicon and OpenGraph: typographic compositions using the author's initials/name and the page palette, made for this portfolio.
- IBM Plex Sans: bundled via @fontsource/ibm-plex-sans, SIL Open Font License.
