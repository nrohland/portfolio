# Asset sources

- Northstar and LendFlow: captures of their public live demos, 2026-10-01, converted to WebP for transfer size. The covers are editorial compositions using these real captures.
- Ad Analytics: original portfolio screenshot of the Tableau Public dashboard, retained from the previous branch.
- Barrilito: inline SVG chart from `apps/spike/data/monthly_pulse.csv`, pinned Vaca Muerta repository commit `1c1c30eb9e29901048cbd812eb14f46c109e4439`. Absolute oil production in cubic metres; no live feed or extrapolation.
- Python, dbt, DuckDB, BigQuery, Next.js, React and Tableau: Simple Icons 13.21.0, CC0. Logos remain the trademarks of their owners. Monochrome with adjacent labels. https://simpleicons.org/
- Meltano: official icon from https://github.com/meltano/meltano/blob/main/docs/docs/reference/images/icon.svg, downloaded 2026-10-01. Repo MIT license. Displayed with grayscale filter and adjacent label.
- SQL has no universal official logo; text abbreviation is used instead of inventing a brand mark.
- Favicon and OpenGraph: typographic compositions using the author's initials/name and the page palette, made for this portfolio.
- IBM Plex Sans: bundled via @fontsource/ibm-plex-sans, SIL Open Font License.
